# NoteBox 📝

A simple Java console application for creating, viewing, searching, updating, and deleting notes.

## Features
- Create notes
- View notes
- Search notes
- Update notes
- Delete notes
- Save notes to a local text file
- Load notes when the app starts

## Technologies
Java, ArrayList, OOP, Scanner, File I/O, exception handling.

## Run
From the project folder:

```bash
javac -d out src/com/notebox/*.java
java -cp out com.notebox.Main
```

Or open the project in IntelliJ IDEA or Eclipse and run `Main.java`.
